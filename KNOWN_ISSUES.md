# Known Issues (Public Beta)

- Web can fail to launch on default port if another Metro instance is running.
- Some browsers may require a hard refresh after dependency updates.

## Gameplay / Balance
- Early-mid progression pacing is still being tuned for Waves 20-60.

## UX
- Some dense panels may need additional mobile-first spacing tweaks.

## Social
