# Achievement UI Assets

This directory contains production-ready UI assets for the SimplyIdle achievement system. The assets follow a premium, painterly-tech sci-fi fantasy art direction with metallic trims and subtle runic motifs.

## Asset Directory

### 1. `command-deck-banner.png` (1600x500)
- **Use**: Main header for the Achievement / Command Deck screen.
- **Visual Intent**: A wide-angle view of a futuristic command bridge, setting a high-stakes "epic" tone. Features holographic interfaces and gold-trimmed metallic surfaces.

### 2. `mission-tile-overlay.png` (1200x600)
- **Use**: Background or decorative overlay for individual achievement mission tiles.
- **Visual Intent**: Semi-transparent etched glass aesthetic with glowing circuitry and reinforced metallic corners. Designed to feel like a high-tech data display.

### 3. `records-plaque.png` (1200x600)
- **Use**: Backdrop for milestone achievements or record-breaking stats.
- **Visual Intent**: Weathered bronze and silver plaque. Industrial engravings mixed with faint magical runes, giving a "historical but futuristic" feel.

### 4. `collection-vault-panel.png` (1200x600)
- **Use**: UI panel for the "Collection Vault" section where trophies are stored.
- **Visual Intent**: Heavy armored vault door aesthetic. Emphasizes security and value through thick metallic plates and complex locking mechanisms.

### 5. `atmosphere-noise.png` (1024x1024)
- **Use**: Tiled background overlay to add texture and grit to UI panels.
- **Visual Intent**: A seamless, low-contrast noise texture featuring dust motes and subtle light streaks. Adds "lived-in" atmospheric depth to flat UI elements.

## Art Direction Notes
- **Style**: Painterly Digital Art (visible brushwork, non-photorealistic).
- **Theme**: Sci-Fi Fantasy / "Ancient Tech".
- **Color Palette**: Deep indigos, gunmetal greys, burnished gold, and glowing cyan accents.
- **Constraints**: No text or logos in textures to ensure localization friendliness and UI flexibility.
