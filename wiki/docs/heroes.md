# Heroes

Status: Partial

Last reviewed: 2026-04-03

## Hero System Overview

- Large roster with class identity and rarity-based scaling.
- Each hero contributes via stat profile, passive traits, and doctrine effects.
- Team performance depends on role fit and synergy, not only raw rarity.

## Rarity Ladder

- Common
- Uncommon
- Rare
- Epic
- Legendary
- Mythic
- Godly
- Transcendent

## Practical Build Rules

1. Stabilize one primary carry and one defensive anchor.
2. Keep class coverage for role-specific passives.
3. Use formation slots to reinforce fragile high-output units.
