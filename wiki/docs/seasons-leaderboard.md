# Seasons & Leaderboard

<span class="status-badge live">Live</span>

Last reviewed: 2026-04-15

## Leaderboard

The global leaderboard ranks all players by **score** — a composite value derived from your overall progression.

### Score Inputs
- Peak wave reached
- Prestige count
- Hero roster strength
- Equipment power
- Facility levels

### Leaderboard Display
Each entry shows:
- Rank position
- Player name and level
- Score
- Guild affiliation (if any)
- VIP badge (if applicable)

Select any leaderboard entry to view the full [Player Profile](/social#player-profiles).

## Seasons

Seasons are periodic competitive cycles that reset rankings and grant exclusive rewards.

### Season Structure
- Each season has a defined start and end date
- During a season, leaderboard scores accumulate
- At season end, rewards are distributed based on final rank

### Tier Brackets

| Tier | Rank Range | Reward Tier |
|------|-----------|-------------|
| Legend | Top 1% | Premium |
| Diamond | Top 5% | High |
| Platinum | Top 15% | Medium-High |
| Gold | Top 30% | Medium |
| Silver | Top 50% | Standard |
| Bronze | Bottom 50% | Participation |

### Season Rewards
- **Diamonds** — scaled by tier
- **Exclusive cosmetics** — season-specific badges
- **Shards and essence** — scaled by tier
- **Titles** — seasonal rank titles visible on profile

### Between Seasons
- Leaderboard scores carry over as a starting baseline
- Historical season results are archived
- Best season performance is displayed on profile
