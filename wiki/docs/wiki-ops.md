# Wiki Ops

## Ownership Matrix

- Core formulas and progression pages: gameplay owner
- Heroes and equipment reference pages: systems owner
- Social, season, and leaderboard pages: live-service owner
- Strategy guides: design owner with QA review

## Required Metadata Standard

For every page update:

- Keep title frontmatter
- Add status label in body: Live, Partial, or Planned
- Include truth source list at bottom
- Include Last reviewed date line for substantial edits

## Patch Day Procedure

1. Review patch notes and implementation deltas.
2. Update affected pages and values.
3. Run local build.
4. Submit PR with source links in description.

## Monthly Review Procedure

1. Spot-check formulas against game constants.
2. Verify social/season state labels still match implementation.
3. Archive stale notes and mark planned sections clearly.
