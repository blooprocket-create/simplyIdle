# Wiki Standards

## Page Metadata

Every page should include:

- title
- status label in body: Live, Partial, or Planned
- truth source list at bottom
- last review date when substantial edits are made

## Truth Hierarchy

1. Code constants and state logic
2. Rules, policy, and contracts
3. Narrative design docs

If sources disagree, prefer higher-priority sources and annotate the discrepancy.

## Update Cadence

- Patch windows: Tuesday and Friday
- Hotfix updates for blocking behavior
- Monthly stale-content review for formulas and live-service values

## Writing Style

- Technical and concise
- Player-focused language
- No hidden assumptions about internal tooling

## Scope Guard

Player wiki pages should avoid deep developer API internals unless directly needed for player understanding.
