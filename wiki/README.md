# SimplyIdle Wiki

Player-facing wiki for SimplyIdle.

## Quick Start

1. Install dependencies:
   npm install
2. Run local docs server:
   npm run docs:dev
3. Build static wiki:
   npm run docs:build
4. Regenerate data-driven reference pages:
   npm run docs:generate

## Run From Repository Root

- Dev server: npm run wiki:dev
- Regenerate data pages: npm run wiki:generate
- Build: npm run wiki:build

## Scope

V1 includes:
- Core mechanics and progression
- Heroes and equipment reference
- Social systems
- Seasons and leaderboard
- Strategy guides
